# ncm2music — NCM 音乐格式转换器（命令行批量版）

把网易云音乐的 NCM 加密文件转换回正常的 **MP3 / FLAC**。

> English version: [README_EN.md](README_EN.md)

- **零依赖**：有 Python 3.7+ 就能跑，不用装任何第三方库
- **纯本地**：解密在本地完成，不联网、不上传
- **自动识别**：NCM 内部实际是 MP3 还是 FLAC，自动判断并起对应后缀
- **标签完整**：自动写入 歌名 / 艺术家 / 专辑 / 封面图（MP3 写 ID3v2.3，FLAC 写 Vorbis Comment + PICTURE）
- **智能命名**：输出文件自动命名为 `艺术家 - 歌名.flac`，无元数据时保留原文件名

## 快速开始

```bash
# 转换单个文件（输出到同目录）
python ncm2music.py "D:\Music\歌曲.ncm"

# 转换整个文件夹下的所有 NCM
python ncm2music.py "D:\Netease\CloudMusic\Cache"

# 递归处理子目录 + 指定输出目录（推荐）
python ncm2music.py -r -o "D:\转换输出" "D:\Netease\CloudMusic"

# 转换成功后删除源 NCM 文件（省空间，慎用）
python ncm2music.py -m -o "D:\转换输出" "D:\Netease\CloudMusic"
```

> Windows 下建议在 PowerShell / CMD 里运行；路径带空格记得加引号。

## 参数说明

| 参数 | 说明 |
|------|------|
| `targets`（必填） | NCM 文件或包含 NCM 的目录，可以一次给多个，空格隔开 |
| `-o, --out <目录>` | 输出目录（默认输出到源文件所在目录，不存在会自动创建） |
| `-r, --recursive` | 递归处理子目录（目录模式下生效） |
| `-m, --delete-src` | 转换成功后删除源 NCM 文件 |
| `--no-tags` | 不写入标签和封面，只解出音频本体 |

## 输出规则

- **格式**：由音频内容自动嗅探（`ID3`/帧同步 → MP3，`fLaC` → FLAC，`OggS` → OGG），嗅探不出时回退用文件内置元数据声明的格式
- **文件名**：优先 `艺术家 - 歌名`，取不到元数据时用原 NCM 文件名；非法字符自动替换为 `_`
- **同目录重复**：同名会直接覆盖，注意保留原文件时别往同一目录重复转

## 常见问题

**Q：提示"不是有效的 NCM 文件"？**
文件不是网易云下载的 NCM 格式，或已损坏。网易云 3.0+ 部分版本下载的文件可能是普通 MP3，直接改名就能用，无需本工具。

**Q：封面没写进去？**
网易云 3.0 之后的某些版本下载的 NCM 不内置封面图（工具会正常转换音频，只是没有封面可写）。想补封面可后续用音乐标签软件（如 MusicBrainz Picard）匹配。

**Q：速度如何？**
采用 256 字节周期密钥流 + 大整数整块异或优化，216MB 的 Hi-Res 文件约 2 秒，普通 10MB 的歌几乎秒转。

**Q：安全吗？**
程序启动时会先用 FIPS-197 官方向量对内置 AES 引擎自检，自检失败会直接退出拒绝工作，不会产出坏文件。

## 配套工具：网页版（NCM音乐格式转换器.html）

同目录下的 `NCM音乐格式转换器.html` 是**网页版**转换器，单文件、免安装、双击即用，适合不想碰命令行的场景。

**功能特性**

- 拖拽批量转换（可一次拖入整个文件夹里的多个 .ncm）
- 自动识别 MP3 / FLAC 并嗅探元数据，列表里直接显示歌名、艺术家、专辑
- 自动写入标签和封面（可在页面上取消勾选）
- 每个文件独立进度条，转换完成自动下载（也可改为手动逐个下载 / 一键全部下载）
- 输出文件名自动用 `艺术家 - 歌名`，与 CLI 版规则一致

**使用方法**

1. 双击 `NCM音乐格式转换器.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开
2. 把 .ncm 文件拖进虚线框（或点击选择文件）
3. 等状态变为 ✓ 转换完成，文件自动保存到浏览器下载目录

**安全与可靠性**

- 解密完全在浏览器内完成，**文件不经过任何服务器**（断网也能用）
- 页面打开时自动运行 FIPS-197 官方向量自检，自检不过会红字警告，拒绝工作
- 分块流式处理，216MB 的 Hi-Res 文件也能秒级转换，不占额外内存

**两个版本怎么选**

| 场景 | 推荐 |
|------|------|
| 临时转几首歌、想要图形界面 | 网页版 |
| 批量转换整个音乐库、需要递归目录/删除源文件 | CLI 版 |
